git add . -> Initializes a commit
git commit -m "add text here" -> add commit information 
git branch -> shows all branches and branch currently on (the one currently on is defined with a * at the beginning)
git switch branch_name -> switches to selected branch
git switch -c newBranchName sourceBranchName -> creates new branch from source branch and switches to it
git branch newBranchName sourceBranchName -> creates new branch from source but stays in current branch
