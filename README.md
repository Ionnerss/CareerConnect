# CareerConnect

**Optional feature: **

1. Skill Gap Map:

  Idea:  The users save many job postings which they are interested in and the system analyzes and notes down the skills missing from the user's profile/resume and all job postings. The idea is to give an idea to the users which skills they lack on. It can be quantified as well. For example, 5 jobs require java, 3 jobs require C++, 2 jobs require SQL, but the user only knows c++, so the systems will suggest with classification which is the most important to the least important. Java being the user's lacking skill more in demand and and SQL being in second place.
